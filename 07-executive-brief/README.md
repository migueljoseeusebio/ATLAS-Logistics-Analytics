# 07 — Executive Logistics Brief

## Challenge

If only three minutes were available with a logistics director, what evidence should be shown and which decision should be recommended?

## Story structure

1. Current operational position
2. Material performance gap
3. Validated driver or risk
4. Recommended action
5. Expected measure of success

## Communication principles

- Lead with the decision, not the chart.
- Use only the evidence required to support the message.
- Separate observation from interpretation.
- State uncertainty and data limitations.
- Assign a measurable follow-up.

## Decision supported

Translate analytical findings into an operational action that leadership can approve, assign and monitor.

## Public evidence

The presentation will be exported to PDF or images after metadata and visual review; the editable source remains private until approved.
