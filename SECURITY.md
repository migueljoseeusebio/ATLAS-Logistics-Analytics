# Security and data policy

This repository is designed for public demonstration. It must not contain:

- credentials, API keys, tokens or connection strings;
- personal, customer, employee or supplier data;
- confidential company information;
- production endpoints or internal system names;
- unreviewed workbook, Power BI or document metadata.

All public records must be synthetic or anonymised. Before publishing a binary file, inspect its document properties, hidden sheets, queries, data connections, comments and embedded source data.

If sensitive information is discovered, remove it from both the current files and Git history before making the repository public.
