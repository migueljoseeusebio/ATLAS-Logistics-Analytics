# 06 — Logistics KPI Dictionary

## Problem

A dashboard can be visually correct and still mislead if metric definitions differ between teams.

## Governance template

Every KPI is documented through:

1. Definition
2. Formula
3. Required data
4. Worked example
5. Interpretation
6. Limitations
7. Common pitfalls
8. Supported decision

## KPI scope

OTIF, OTD, lead time, fill rate, dwell time, cost per shipment, cost per kilometre, capacity utilisation, empty running, SLA compliance, incident rate, MTTR and recurrence.

## Decision supported

Create a shared operational language and prevent inconsistent calculations across Excel, SQL and Power BI.

## Public evidence

The reviewed KPI dictionary will be published in an accessible Markdown format before the source workbook is added.
